# Linear vs. Deep Learning Dimensionality Reduction

Stat 6130 (Multivariate Analysis) final project, Spring 2026 — John Pendergrass.

This project compares **PCA**, **classical MDS**, and **autoencoders** (fully connected and,
for images, convolutional) for dimensionality reduction across three settings of increasing
complexity: synthetic manifolds, the COIL-20 image dataset, and TCGA breast cancer gene
expression data. Methods are evaluated on reconstruction error (with paired hypothesis tests),
2-D visual structure, and downstream classification accuracy of the learned embeddings.

## Experiments

### 1. Synthetic data — `synthetic_data.py`
- **Datasets** (n = 1000): a noisy 2-D linear subspace embedded in 20 dimensions, the S-curve,
  and the Swiss roll (`sklearn.datasets`).
- Compares reconstruction MSE and 2-D embeddings for PCA, MDS, and an MLP autoencoder
  (latent dim 10, hidden-layer/learning-rate grid search).
- **Figures:** `linear_subspace_*`, `s-curve_*`, `swiss_roll_*` (`_2d.png` embeddings, `_mse.png` error distributions).

### 2. COIL-20 — `coil20_analysis_final.py`
- 1,440 grayscale 128×128 images of 20 objects photographed at 72 rotation angles.
- Adds a convolutional autoencoder and checks whether embeddings recover the rotation
  structure (Spearman pose correlation, circularity scores), plus SVM classification of
  objects from 10-D embeddings.
- Uses Apple Silicon GPU (`mps`) when available, otherwise CPU.
- **Figures:** `coil20_2d_by_object*.png`, `coil20_circular_structure.png`,
  `coil20_rotation_metrics.png`, `coil20_mse.png`, `coil20_classification.png`.

### 3. TCGA BRCA — `tcga_analysis.py`
- RNA-seq expression for TCGA Breast Invasive Carcinoma samples; the top 2,000 most
  variable genes are kept. Samples are labeled Tumor / Normal / Metastatic from barcodes.
- Autoencoder hyperparameter search (hidden dims, learning rate, dropout), PCA explained
  variance, and logistic-regression classification of tumor vs. normal from embeddings.
- **Figures:** `tcga_pca_variance.png`, `tcga_hp_search.png`, `tcga_2d_by_type.png`,
  `tcga_mse.png`, `tcga_classification.png`.

## Data

The raw datasets aren't in this repository (they're large). Download them separately:

| Dataset | Source | Expected path |
|---|---|---|
| COIL-20 (processed) | [Columbia CAVE — COIL-20](https://www.cs.columbia.edu/CAVE/software/softlib/coil-20.php) (`coil-20-proc.zip`) | `data/coil-20-proc/` (unzipped) |
| TCGA BRCA HiSeqV2 | [UCSC Xena — TCGA Breast Cancer (BRCA)](https://xenabrowser.net/datapages/) gene expression RNAseq, `HiSeqV2` | `data/HiSeqV2.gz` |

Paths are resolved relative to the scripts themselves (`COIL_DIR` in
`coil20_analysis_final.py`, `DATA_PATH` in `tcga_analysis.py`), so the scripts can be run
from any working directory. The synthetic experiment generates its own data.

## Setup & usage

```bash
pip install numpy pandas matplotlib scikit-learn scipy torch pillow

python synthetic_data.py
python coil20_analysis_final.py
python tcga_analysis.py
```

Each script prints reconstruction-error summaries and test results to the console and
saves its figures to `figures/` (overwriting the committed versions). All runs use `RANDOM_SEED = 42`.

To build the report, compile `report/report.tex` with the PNGs from `figures/` on the
LaTeX graphics path (e.g. add `\graphicspath{{../figures/}}`, or copy them next to the `.tex`).
